# Insta-Dotfiles Migration Design

## Goal

Migrate work laptop (insta-laptop) dotfiles from `ziyunli/insta-dotfiles` repo into this unified dotfiles repo, then archive the old repo.

## Design

### Shared Shell Config

Create `shared/.zshrc.common` containing generic shell configuration:

- oh-my-zsh setup (theme: agkozak, plugins)
- Editor settings (`EDITOR`, `VISUAL`)
- Aliases: vim, brewski, du, ping, top, eza/ls, git_delete_squashed
- FZF configuration and functions (branches, delete-branches, pr-checkout, activate-venv)
- Generic PATH additions
- asdf init
- zsh-syntax-highlighting

### Device-Specific Config

Create `devices/insta-laptop/.zshrc` that:

1. Sources `~/.zshrc.common`
2. Adds work-specific config:
   - `source ~/.instacart_shell_profile`
   - Bento completions block
   - nvm/load-nvmrc hook
   - gohan setup
   - terraform alias (`~/tf-instacart/isc-terraform`)

### Excluded from Migration

These files are either auto-generated or already covered:

- `.instacart_shell_profile` - auto-generated by Instacart setup scripts
- `.ssh/allowed_signers` - not needed
- `.zprofile` - skipped
- direnv hook - skipped
- `.claude/` - using shared version
- `.gitconfig` - using `.gitconfig.local` pattern
- Files already in shared/: `.tmux.conf`, `.taskrc`, `.tigrc`, `.gitignore_global`, `.config/pgcli/config`

### Post-Migration

1. Run `install.sh insta-laptop` on work machine
2. Create `~/.gitconfig.local` with work email and signing key
3. Archive `ziyunli/insta-dotfiles` repo

## File Structure After Migration

```
shared/
  .zshrc.common          # NEW: generic shell config
  ... (existing files)

devices/
  insta-laptop/          # NEW
    .zshrc               # sources common, adds work config
  bento/
  Ziyuns-Mac-mini/
```
